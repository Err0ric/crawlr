# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. I aim to acknowledge reports within a few days.

## Scope

In scope: the code in this repository and the hosted site at https://crawlr.lol.

Out of scope: the third-party sources CrawlR queries, denial-of-service testing against the hosted site, and social engineering.

## Supported versions

Only the current `main` branch, which is what https://crawlr.lol runs.
