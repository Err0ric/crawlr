How to read a case

Every row carries one of five standings. The line says how it is known, the color says which.

  • FlagChanges the risk picture: a breach, a known CVE, a malware verdict.
  • LinkedTied to the person by a strong signal, or the record for the target itself.
  • MatchesA profile was read and nothing on it conflicts.
  • Different personA profile was read and the name on it conflicts.
  • UnverifiedA tool reported it and nothing was read. A lead to check.

A solid line means a source read or checked it. A dashed line means it was reported and nothing checked it. A failed source is shown as failed, never as "not found".

Where to find raw headers
  • Gmail: open the message, the three-dot menu, Show original.
  • Outlook (web): the three-dot menu, View, View message source.
  • Outlook (desktop): File, Properties, Internet headers.
  • Apple Mail: View, Message, All Headers.
