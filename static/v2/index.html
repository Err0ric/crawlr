Where to find raw headers
  • Gmail: open the message, the three-dot menu, Show original.
  • Outlook (web): the three-dot menu, View, View message source.
  • Outlook (desktop): File, Properties, Internet headers.
  • Apple Mail: View, Message, All Headers.
